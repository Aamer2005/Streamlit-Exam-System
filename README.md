# Online Examination System

A complete web-based examination system with three user roles:
- 👨‍🏫 Teachers: Create and manage exams
- 👨‍🎓 Students: Take exams and view results  
- 👨‍💼 Admins: Manage users and view analytics

## Features
- Secure user authentication
- Real-time exam timer
- Automatic grading
- Performance analytics
- Responsive design
